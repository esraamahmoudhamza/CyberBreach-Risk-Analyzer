# 🛡 CyberBreach Risk Analyzer

A simple cybersecurity web dashboard built with Flask that simulates email/username breach analysis and visualizes risk levels in real time.

---

## 🚀 Features

- Analyze email or username input
- Simulated breach database
- Risk scoring system (0–100)
- Risk classification:
  - LOW 🟢
  - MEDIUM 🔵
  - HIGH 🔴
- Interactive charts using Chart.js
- Modern dark UI dashboard

---

## 🧠 How It Works

The backend checks the input against a small simulated database.  
If not found, it generates random breach data.

Risk is calculated using:

- Number of breaches
- Randomized security factor

Then it returns a JSON response to the frontend for visualization.

---

## 🛠 Tech Stack

- Python (Flask)
- HTML5 / CSS3
- JavaScript (Vanilla)
- Chart.js

---

## ⚠️ Disclaimer

This project is for educational and demonstration purposes only.
It does not perform real breach detection.
